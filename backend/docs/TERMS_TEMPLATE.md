# MarketPilot Terms — TEMPLATE

This is only a starting template and is not legal advice.

Include:
- service description
- eligibility
- account security
- acceptable use
- market-data limitations
- AI output limitations
- investment-risk disclosure
- no guarantee of returns
- third-party provider terms
- intellectual property
- subscription/payment terms if applicable
- termination
- account deletion
- dispute/governing law
- support/contact details

Before launch, have an India-qualified lawyer review this together with the actual product functionality.
