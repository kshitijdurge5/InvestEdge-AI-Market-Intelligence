INVESTEDGE MOBILE STARTER
=========================

Flutter starter for the future Android + iOS client.

Current screen: branded welcome screen.
Next integration stages:
1. API base URL configuration
2. Registration: name + username + email/phone
3. OTP verification
4. Password creation
5. Secure session storage
6. GET /auth/me
7. Personalized dashboard
8. Account deletion / privacy controls

Do not place Upstox secrets, API keys, JWT secrets, or database credentials in the mobile app.
