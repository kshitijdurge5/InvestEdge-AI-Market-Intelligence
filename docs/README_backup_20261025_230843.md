## Overview

InvestEdge is a personal software engineering and AI learning project focused on market information, investment research workflows, and AI-assisted financial insights.

The project brings together a Flutter application, a Python backend, real-time communication concepts, data storage, and AI/LLM integration.

It demonstrates my practical learning across application development, backend engineering, API integration, and AI-enabled software design.

## Project Goals

- Explore AI-assisted market research and financial information.
- Build a mobile interface using Flutter and Dart.
- Develop backend services with Python and FastAPI.
- Explore WebSockets for real-time data communication.
- Use SQLite for lightweight data persistence.
- Learn how to structure and integrate AI-powered application features.
- Improve software engineering practices, documentation, and deployment workflows.

## Getting Started

1. Clone this repository.
2. Review the project folders and component-specific instructions.
3. Install the required dependencies for the relevant component.
4. Configure required API credentials using local environment variables.
5. Run the backend and mobile application according to their setup instructions.

Exact commands depend on the current dependency files and project configuration.

**Security:** Never commit API keys, access tokens, passwords, signing keys, or personal information.
