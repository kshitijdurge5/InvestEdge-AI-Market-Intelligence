# InvestEdge — AI Market Intelligence

## Overview
InvestEdge is a personal software project exploring AI-assisted
market research and investment information.

## Technologies
- Python
- Flutter / Dart
- FastAPI
- WebSockets
- SQLite
- AI/LLM integration

## Project status
Personal learning and portfolio project. Feature availability,
live market connectivity, and deployment readiness must be verified.

Do not use this project as financial advice. Market data and AI
outputs may be incomplete or inaccurate.

## Setup
Review the individual component instructions before running.
Configure credentials using local environment variables.
Never commit API keys, access tokens, passwords, or signing keys.
